HealthDash — Privacy Policy

Last updated 1 August 2026

HealthDash is a private, single-user application built and operated by one person for his own use. It is not a product, not offered to the public, and has no other users. All data it holds is stored on a Raspberry Pi on a private home network and is never sold, shared, or transmitted to any third party.

Who runs this

HealthDash is built and run by Mikael Papantoniou as a personal project. The only person who can sign in is the single Google account on its allowlist. There is no sign-up, and no mechanism for anyone else to create an account.

What data is collected

Only data belonging to the operator, drawn from services he has personally authorised:

  • WHOOP — sleep, recovery, physiological cycles, workouts, body measurements, and where the hardware supports it, skin temperature and blood oxygen.
  • Apple Health — metrics exported from his own iPhone.
  • Renpho — body-composition readings, received via Apple Health.
  • Govee — ambient temperature and humidity from his own sensor.
  • Personal medical documents — his own records, added manually.

No data is collected from anyone else. There are no analytics, no advertising identifiers, no tracking pixels, and no third-party scripts on this site.

Where the data is stored

All data is stored in a SQLite database on a Raspberry Pi on a private home network. It is not stored in any cloud database, and the server is not shared with any other party. Personal medical documents are held only on that device and are deliberately excluded from any synchronisation to external services.

How the data is used

Solely to display the operator's own health information back to him in a personal dashboard. It is not analysed for any commercial purpose, not used to train any model, not profiled, and not disclosed to anyone.

Authentication

Sign-in uses Google OAuth. HealthDash requests only the openid and email scopes — enough to confirm which account is signing in, and nothing more. It has no access to Gmail, Drive, Calendar, or contacts. It does not store a Google refresh token and holds no ongoing access to any Google account.

Data sharing

None. Data is never sold, rented, shared, or transferred. There are no advertisers, data brokers, analytics providers, or third-party processors. Data is disclosed only where legally compelled.

Retention and deletion

Data is retained for as long as the operator finds it useful, and can be deleted by him at any time by removing it from the device. Access granted to HealthDash by any connected service can be revoked at any time from that service's own settings — for WHOOP, via the WHOOP app's connected-apps screen; for Google, via the Google account permissions page. Revoking access stops all further data collection immediately.

Security

All connections use HTTPS. The API is reachable only through an authenticated tunnel, binds to localhost on the server itself, and every endpoint carrying health data requires a valid signed session belonging to an allowlisted account. Credentials are stored in a permission-restricted file on the device and are never committed to source control.

Not medical advice

HealthDash displays measurements recorded by consumer devices. It is not a medical device, provides no diagnosis or clinical interpretation, and must not be relied on for medical decisions.

Children

HealthDash is used by one adult and is not directed at children.
